# Final ET9P reproduction check

This folder contains the final Phase 9 reproduction check rerun on the original analysis machine.

The rerun reproduced the locked manuscript results, including:

- 1,641 matched records
- 54 occupied 3-km blocks
- ET9P RMSE ≈ 39.77 Mg/ha
- ET9P MAE ≈ 33.10 Mg/ha
- R² ≈ 0.0829
- ET9P improved RMSE in 5/5 outer folds
- paired 3-km block bootstrap with 5,000 replicates
- held-out permutation importance
- residual Moran's I diagnostics

These files provide an audit trail for the final manuscript-level ET9P analysis.
