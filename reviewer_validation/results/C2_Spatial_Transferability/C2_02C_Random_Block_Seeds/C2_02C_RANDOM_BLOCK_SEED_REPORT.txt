DESIGN
--------------------------------------------------------------------------------------------------
Ten block-to-fold assignments were frozen before any C2 model performance was observed.
All 54 pre-existing 3-km spatial blocks remained indivisible units.
Each random assignment used five outer folds and a 500-m training exclusion buffer.
No AGBD or predictor values were used when assigning blocks to folds.
Frozen model family: Extra Trees.
Frozen predictor family: full 14P multiscale set.
ET hyperparameters were retuned only within each active training sample using four-fold GroupKFold by cv_block_id.
No model-family or feature-family selection occurred.
