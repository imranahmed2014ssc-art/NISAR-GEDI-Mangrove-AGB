METHOD
----------------------------------------------------------------------------------------------
54 pre-existing 3-km spatial blocks remain indivisible units.
Blocks are ranked by sample count and processed in batches of five.
Within each batch, block order and fold labels are randomized using the locked seed.
This approximately balances block sampling density without using AGBD or predictor values.
A 500-m train-test exclusion buffer is applied after each assignment.
